# Contributing To The Wiki

## Principles

- Keep pages practical and implementation-focused
- Prefer short sections with explicit file paths and commands
- Update wiki pages in the same pull request as code changes

## Suggested Update Rules

- Add setup or runbook changes to `Getting-Started.md`
- Add architectural shifts to `Architecture.md`
- Add backend-specific conventions to `Backend-Guide.md`
- Add app-specific conventions to `App-Guide.md`

## Page Style

- Use Markdown headings in logical order
- Use fenced code blocks for commands
- Keep examples current and verifiable
- Avoid duplicate content when a source doc already exists
