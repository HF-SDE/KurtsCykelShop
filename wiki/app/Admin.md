On the admin page, you can manage various aspects of the application, including user accounts, and order management. The admin page is typically accessible only to users with administrative privileges.

# Accessing the Admin Page

To access the admin page, follow these steps:

1. Log in to the app with an account that has admin privileges.
2. Once logged in, navigate to the admin page using the bottom tab navigation.

<img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/navbar%20admin.png" height="200">

# User Management

- View a list of all registered users
- Edit user details such as name, email, and role
- Reset user passwords
- Archive user accounts
- Assign roles to users

## Navigation
To access the user management features, navigate to the "Users" section within the admin page.

<img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/admin%20nav%20users.png" height="500">

See [User Management Page](User-Management) for more details on how to manage user accounts.

# Role Management

- View a list of all roles available in the system
- Create new roles with specific permissions
- Edit existing roles and their associated permissions

## Navigation
To access the Role management features, navigate to the "Roles" section within the admin page.

<img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/admin%20nav%20roles.png" height="500">

See [Role Management Page](Role-Management) for more details on how to manage roles and permissions.

# Important Notes

- Always ensure that you have the necessary permissions to access and manage the admin page.
- Be cautious when making changes to user accounts and roles, as these actions can have significant impacts on the system and its users.
- If you encounter any issues while using the admin page, refer to the documentation or create a issue for assistance.
