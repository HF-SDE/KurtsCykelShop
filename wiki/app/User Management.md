On the User Management page, you can manage user accounts, including creating new users, editing existing users, and archiving users. This page is typically accessible to administrators or users with the appropriate permissions.

# features

- View a list of all users with their details (e.g., username, email, role).
- Edit user information (e.g., change role, update email).
- Archive users who are no longer active (soft delete).
- Search and filter users based on criteria such as username or role.

# Create New User

To create a new user, follow these steps:

1. Click on the "+" button in the right corner of the User Management page.
   <img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20create%20button.png" height="500">

2. Fill in the required information for the new user, such as username, email, password, and role.
   <img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20create%20form.png" height="500">

3. Select a user role from the dropdown menu. You can select multiple roles for a user if needed.
   <img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20create%20role%20selector.png" height="500">

3.1. If you want to remove a role from the user, simply click on the "x" next to the role name in the dropdown menu.
<img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20create%20role%20remove.png" height="500">

3. Click the "Save" button in the right corner to create the new user. If the user is created successfully, you will see a confirmation message. If there are any issues (e.g., missing required fields, username already taken), you will see an error message with details on how to resolve it.
   <img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20create%20save.png" height="500">

# Edit User

To edit an existing user, follow these steps:

1. Swipe Left on the user you want to edit from the list of users and click on the the Pincel.
   <img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20swipe%20left.png" height="500">

2. Update the user's information as needed (e.g., change role, update email).
   <img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20edit.png" height="500">

3. Select a user role from the dropdown menu. You can select multiple roles for a user if needed.
   <img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20edit%20role%20selector.png" height="500">

3.1. If you want to remove a role from the user, simply click on the "x" next to the role name in the dropdown menu.
<img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20edit%20role%20remove.png" height="500">

4. Change the users password. Click on "Nulstil password".
   <img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20edit%20change%20password%20button.png" height="500">

4.1 Enter the new password in the "Nyt password" field and confirm the new password by entering it again in the "Bekræft nyt password" field.
<img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20edit%20change%20password.png" height="500">

4.2 Click on the "Gem" button to save the new password. If the password change is successful, you will receive a confirmation message. If there are any issues (e.g., weak password, passwords do not match), you will see an error message with details on how to resolve it.
<img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20edit%20change%20password%20save.png" height="500">

5. Click the "Save" button in the right corner to save the changes. If the user is updated successfully, you will see a confirmation message. If there are any issues (e.g., missing required fields, username already taken), you will see an error message with details on how to resolve it.
   <img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20edit%20save.png" height="500">

# Archive User

## On Overview

To archive a user, follow these steps:

1. Swipe right on the user you want to archive from the list of users and click on the Trash icon.
   <img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20swipe%20right.png" height="500">

2. Confirm the action by clicking "Arkiver" in the confirmation dialog. Archiving a user will deactivate their account and remove their access to the app, but their data will still be retained in the system for record-keeping purposes.
   <img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/users%20archive.png" height="500">

## On User Detail/Edit page

1. Click on the "Disable" in the button.
   <img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20edit%20archive.png" height="500">

2. Confirm the action by clicking "Bekræft" in the confirmation dialog. Archiving a user will deactivate their account and remove their access to the app, but their data will still be retained in the system for record-keeping purposes.
   <img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20edit%20archive%20Confirm.png" height="500">

# Search Users

To search and filter users, follow these steps:

1. Use the search bar at the top of the User Management page to search for users by username, email, or other criteria. As you type, the list of users will dynamically update to show matching results.
   <img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20search.png" height="500">

# Filter Users

1. Use the filter options to narrow down the list of users based on specific attributes such as role, status (active/arkiverede/alle).
2. Click on the filter icon next to the search bar to open the filter menu.
   <img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20filter%20button.png" height="500">

3. Select the desired filter (e.g., kontostatus)
   <img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20filter%20selected.png" height="500">

4. Select the desired filter criteria (e.g., kontostatus)
   <img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20filter.png" height="500">

5. Click on "Anvend" to update the user list based on the selected filters.
   <img src="https://raw.githubusercontent.com/HF-SDE/KurtsCykelShop/refs/heads/main/.github/images/wiki/user%20filter%20apply.png" height="500">

6. The list of users will update to show only those that match the selected filter criteria.
